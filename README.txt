JESSICA.DEV — PORTOFOLIO HTML, CSS, DAN JAVASCRIPT

Versi terbaru: foto Jessica transparan di tengah, pengenalan di kiri, biodata di kanan. Warna navy, peach, dan burgundy. Foto sudah disertakan.

CARA MEMBUKA
1. Klik kanan ZIP > Extract All / Ekstrak Semua.
2. Buka folder jessica-dark hasil ekstrak.
3. Klik dua kali index.html. Jangan membuka HTML langsung dari dalam ZIP.
4. Pertahankan style.css, script.js, serta folder assets dalam susunan aslinya.
Website tidak membutuhkan instalasi atau internet untuk aset yang disertakan.

MENGGANTI DATA
- Biodata, pendidikan, pengalaman, dan proyek: edit index.html. Cari teks dalam tanda [ ].
- Foto: letakkan foto-jessica.png pada folder yang sama dengan index.html. Foto tanpa latar paling sesuai. Jika tidak tersedia, inisial J tetap tampil.
- Gambar proyek/kegiatan: ganti div media-placeholder yang sesuai dengan tag img, contohnya <img src="assets/proyek.jpg" alt="Nama proyek">, lalu letakkan gambar di assets.
- Sertifikat: letakkan gambar di assets; ganti KEDUA src assets/certificate-placeholder.svg (kartu dan modal) dalam index.html. Ganti judul, alt, penerbit, dan tahun di keduanya.
- Kontak: isi CONTACTS pada awal script.js. value email berisi alamat email; value media sosial berisi URL https lengkap. label adalah teks yang ditampilkan. Kosongkan value untuk mempertahankan placeholder tanpa tautan.
- Tautan proyek: tambahkan <a href="https://alamat-asli">GitHub / Demo</a> di tempat komentar yang tersedia setelah alamat asli ada.
- Warna: ubah variabel pada :root di style.css.
- Kecepatan logo: ubah 100s pada animasi marquee di style.css; nilai lebih besar berarti lebih lambat.

INTERAKSI
Menu HP, tab Projects/Certificates (termasuk tombol panah), modal sertifikat, navigasi aktif, kembali ke atas, efek mengetik, dan animasi scroll.
Reduced motion mengikuti pengaturan perangkat, termasuk jika diubah saat halaman terbuka.
Tanpa JavaScript, konten utama, logo, pendidikan, serta kedua bagian karya tetap terlihat. Logo berhenti sementara saat kursor atau fokus keyboard berada pada deretan logo.
